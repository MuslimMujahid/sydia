# Local font assets

Inter (normal, weights 400–800) and JetBrains Mono (normal, weights 400–500) retain the original Google Fonts families and Unicode subsets. Each family includes its upstream SIL Open Font License in `OFL.txt`.

Source stylesheet: https://fonts.googleapis.com/css2?family=Inter:wght@400..800&family=JetBrains+Mono:wght@400..500&display=swap

Licenses: https://github.com/google/fonts/tree/main/ofl/inter and https://github.com/google/fonts/tree/main/ofl/jetbrainsmono. Downloaded 19 October 2026.

Inter Tight remains scoped to authentication/Profile and has its own license in `inter-tight/OFL.txt`.
