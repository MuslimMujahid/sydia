# Chat preview logos

- `telegram.svg`: original SVG from [Telegram](https://telegram.org/img/t_logo.svg), linked from its [press resources](https://telegram.org/press).
- `whatsapp.svg`: WhatsApp mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/whatsapp.svg), with its brand green fill. Simple Icons assets use the [CC0 license](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
- The Web chat panel uses the existing Sydia `/logo.svg`.

These assets identify the local test channels. The native preview colors are scoped to the preview page and do not change the Sydia design system.
